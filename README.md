# Battery Management Systems

A personal portfolio of code and projects exploring battery modelling and Battery Management Systems (BMS).

This repository documents my practical work and learning, with an emphasis on understanding the methods, implementing algorithms, and interpreting results.

## Scope

Areas of interest include:

- Battery modelling using equivalent circuits.
- Open-circuit voltage (OCV) characterisation.
- State-of-charge (SOC) estimation.
- Battery data analysis and visualisation.

## Project organisation

Projects will be added progressively in separate folders. Each project will include an explanation of its purpose, the code, instructions for running it, and results where available.

## References and contributions

Work based on courses, publications, or existing implementations will identify the original sources and distinguish my contributions and modifications.

## Status

Work in progress. Code, documentation, and results will be added as the projects develop.
